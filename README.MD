## 💻 Pré-requisitos

Antes de começar, verifique se você atendeu aos seguintes requisitos:

- Você instalou a versão mais recente do `Python 3.13.5`

## 🚀 Criando um ambiente virtual eGestor

Acesse o arquivo eGestor-backend e execute os seguintes comandos:

Windows:

```
pip install -r requirements.txt - instalar as dependências do Flask
```
```
python3 -m venv venv - para criar um ambiente virtual.
```
```
Clique em start.bat para ligar o back-end.
```

## ☕ Usando eGestor

Para usar eGestor, siga estas etapas:

```
Clique em alguma das páginas para ter acesso ao sistema.
```
